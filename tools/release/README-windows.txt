Kinetra-Lab for Windows (64-bit), built from commit @COMMIT@

Start kinetra.exe: the launcher opens Demo, Dotio and i4sim.
Each application also runs on its own: kinetra_demo.exe, kinetra_dotio.exe, kinetra_i4sim.exe.

Requirements: Windows 10 or later and a graphics driver with OpenGL 3.3.
Nothing needs to be installed. Keep SDL2.dll and the i4sim-blueprints folder
next to the executables.

Controls: Ctrl or the SETTINGS button opens the settings panel and pauses the run.
The full guides are at https://github.com/SMB-M87/Kinetra-Lab

Windows may warn about an unknown publisher, because the executables are not signed:
choose "More info", then "Run anyway".

Licenses of Kinetra-Lab, Kinetra, SDL2 and nlohmann_json are in licenses/.
