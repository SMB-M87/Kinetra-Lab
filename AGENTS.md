# Kinetra-Lab Agent Guide

## Documentation

- Every first-party project directory must contain a `README.md`. Add one whenever creating a directory or working in an existing directory that lacks it.
- This requirement also applies to test directories, including `launcher/tests/`, `labs/dotio/tests/` and `labs/demo/tests/`.
- Keep each README concise: explain the directory's purpose, its contents and relevant usage. For test directories, describe the coverage and how to build and run the tests.
- Keep READMEs synchronized with changes and link to authoritative documentation instead of duplicating it.
- Generated build directories, third-party dependencies and Git metadata are exempt.
